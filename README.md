# Олимпиадный тренажёр · 5 класс

Веб-тренажёр для подготовки к школьному этапу ВсОШ по математике (5 класс).
Весь тренажёр находится в одном файле, `index.html`, а рядом лежат только значки и файлы для установки на телефон. Он работает без сервера и регистрации: можно открыть двойным кликом или выложить на GitHub Pages.

**Главный принцип:** не угадывай ответ — ищи идею.

## Что внутри

| Раздел | Что делает |
|---|---|
| 🚀 Ветка | Над вкладками выбирается ветка: **🏆 Олимпиада** или **🚀 Школа на шаг вперёд**. При первом входе тренажёр предлагает выбрать. Тренер, темы, разминка и карта навыков показывают только темы выбранной ветки. |
| ⏰ Будильник | Занятие на 1 час (потом 1,5 и 2 часа) с целью по числу верно решённых задач: сначала 5, после выполненной цели +5. Когда время вышло — звонок, вибрация, голосом мотивирующая фраза и итоги: сколько решено, что получилось, что подтянуть, цель и тема на следующий раз. |
| 🏆 Варианты | 7 олимпиадных вариантов по 8 задач — по образцу школьного и пригласительного этапов ВсОШ; варианты 6 и 7 повышенной сложности — и «🎲 Новый вариант» из ещё не решённых задач. Режимы: **Олимпиада** (45 минут, вариантов ответа нет, после сдачи ответов — шаг «обоснуй», баллы 7 / 2 / 0 как на олимпиаде) и **Тренировка** (проверка сразу, подсказки, разбор, обоснование после верного ответа). |
| 🤖 Мой тренер | Находит тему, где ребёнку сейчас трудно, и **сначала объясняет метод**: главная идея, шаги и полностью решённый пример (шаги открываются по одному). Потом даёт 5 похожих задач для самостоятельного решения. Задачи с ошибками позже возвращаются в «Работу над ошибками». |
| 📝 Контрольные | В школьной ветке вместо вариантов: контрольная из 8 задач по 8 темам, 40 минут без подсказок, оценка 5 / 4 / 3 / 2 (7 из 8 — пятёрка) или тренировочная контрольная с подсказками. |
| 🧩 Темы | 20 олимпиадных навыков и 10 школьных. По каждому можно открыть разбор метода или сразу решать задачи. |
| 🔥 Разминка | 5 несложных задач из разных тем. |
| 📈 Мой прогресс | Отчёт за сегодня (время занятий, верно/неверно, что хорошо, что подтянуть), занятия по будильнику, оценки за контрольные и итог за все дни с таблицей по дням. |
| 🗺️ Мир, 🏡 Магазин мира, 🧠 Мастерская | Герой, виртуальный мир (только косметика), творческие задания. |
| 👨‍👩‍👧 Родителю | Таблица по навыкам: самостоятельно / с подсказкой / ошибки; история олимпиад. |

14 навыков: числовые ограничения, закономерности, обратный ход, логические цепочки, гарантия и худший случай, комбинаторный подсчёт, клетчатая геометрия, инварианты (разрезания и игры), остатки и чётность, текстовая модель, а с V31 — движение, периметр и площадь фигур, подсчёт двумя способами, оценка и пример, а с V33 — пространство и повороты, построй пример, разрезания и части, взвешивания и переливания, числовые ребусы, турниры и рукопожатия. Банк — 513 задач (уровни 1–4, где 4 — «олимпиадная»), из них 28 с рисунками и 100 школьных.

### V34: «Школа на шаг вперёд» и будильник

Олимпиадные задачи трудные, и если давать только их, ребёнок часто ошибается и теряет уверенность. Вторая ветка — школьная программа 5 класса чуть выше уровня учебника и темы 6 класса (метка «🚀 6 класс»): ребёнок видит, что уже умеет то, чего в классе ещё не проходили, получает пятёрки за контрольные и с этой уверенностью переходит к олимпиадным задачам. После трёх пятёрок подряд тренажёр предлагает олимпиадную ветку.

10 школьных тем по 10 задач (уровни 1–3), у каждой — разбор метода с двумя примерами: вычисления и порядок действий, задачи на движение, обыкновенные дроби, десятичные дроби, уравнения, площадь/периметр/объём (5 класс); делимость, НОД и НОК, проценты, отношения и пропорции, отрицательные числа (6 класс). Навыки помечены `track:'school'` и `grade`, id задач — `S34-…`.

Будильник (`p.v30.alarm`, история — `p.v30.alarms`) считает все задачи, решённые, пока он заведён, в любой вкладке. Звонок слышно, пока тренажёр открыт; если вкладку закрыли, итоги покажутся при следующем открытии.

### V33: обоснования и баллы как на олимпиаде

На олимпиаде баллы ставят за решение, а не за ответ: верный ответ без объяснения обычно стоит 0–2 балла из 7. Проверять записи на бумаге некому, поэтому тренажёр проверяет рассуждение сам. К каждой задаче вариантов и к трудным задачам (`WHY` в блоке V33) есть три рассуждения **с одним и тем же ответом**: одно полное и верное, а в двух спрятана ошибка — «только пример без доказательства», «только проверка», неверный ход, который случайно дал верное число.

* **Олимпиада:** вариантов ответа нет (поле для ответа; «найдите все» — через запятую). После «Завершить и проверить» открывается шаг обоснований для верных ответов, ответы уже нельзя менять. Баллы: ответ + верное рассуждение — 7, ответ без него — 2, неверный ответ — 0.
* **Тренировка:** после верного ответа нужно выбрать рассуждение. «Самостоятельно» засчитывается только без подсказок, с верным рассуждением и, если были варианты ответа, с первой попытки.
* Задачи «расставьте / приведите пример» проверяются функцией `verify`: подходит любой верный ответ.

## Установка на телефон и превью ссылки

* `manifest.webmanifest` и `icons/` позволяют поставить тренажёр на главный экран как приложение. Инструкция для посетителей находится в разделе «Как пользоваться».
* `sw.js` включает работу без интернета: сначала берётся свежая версия из сети, а без сети открывается последняя сохранённая. Он работает только на https (и на localhost), а при открытии файла двойным кликом не включается.
* `og.png` (1200×630) задаёт картинку превью, когда ссылкой делятся в Telegram, WhatsApp и ВКонтакте. Мета-теги лежат в `<head>` файла `index.html`.

## Как устроен код

Файл исторически состоит из слоёв V8…V29, которые переопределяли друг друга. Отсюда и шли баги.
Поэтому в конце файла добавлен **единый слой V30** (блок между `<!-- V30:BEGIN -->` и `<!-- V30:END -->`). Именно он отвечает за все учебные сценарии:

* `<script id="v30-bank">` — **единственный банк задач** (`V30_TASKS`) и уроки по навыкам (`V30_SKILLS`: идея, шаги, решённые примеры, частая ошибка). Вторая часть блока — пакет V31 по образцу реальных олимпиад (новые навыки, варианты по 8 задач, задачи с выбором ответа), третья — V32, задачи с рисунками. Рисунок задаётся строками клеток: `fig:{map:['.#.','###','.#.']}`, где `#` — клетка фигуры, `o` — вырезанная (белая) клетка; движок рисует его в SVG;
* `<script id="v30-engine">` — навигация, сессии, проверка ответов, подсказки, тренер, сохранение и восстановление, результаты, статистика.

Старые слои остались ради героя, мира, магазина, мастерской и аккаунта. Их кнопки запуска сессий перенаправлены в V30, а их старые экраны спрятаны.

Прогресс хранится в `p.v30` через `getP()`/`setP()`: и гостю, и ученику с аккаунтом — в `localStorage` этого браузера, поэтому прогресс не пропадает после закрытия вкладки. На сервер ничего не отправляется. Прогресс из старых версий (уже увиденные задачи, незавершённая работа) переносится автоматически.

Дневник занятий — `p.v30.days['ГГГГ-ММ-ДД'] = {sec, ind, ast, wrong, sk}`: ответы по навыкам и время. Время идёт, только пока открыты задачи, урок или разбор, вкладка на виду и за последние 5 минут было хоть одно действие (клик, ввод, прокрутка).

### Как добавить задачу

Добавьте строку в массив `V30_TASKS` в блоке `v30-bank`:

Задачи с выбором ответа добавляются через `Q(...)` с последним аргументом `{type:'choice', options:[...]}`, `{type:'multi', options:[...]}` (ответ `'6;7;8'`) или `{type:'match', rows:[...], options:[...]}` (ответ `'а|б|в'` в порядке `rows`).

```js
T('V30-N20','numbers',2,'train','Название','Текст задачи','Ответ','идея (для подсказки 2)','конкретный первый шаг (подсказка 3, без ответа)','Полное решение', ['другие','формы','ответа']),
```

* навык — один из 20 `id` в `V30_SKILLS`; уровень — 1, 2, 3 или 4;
* в блоке V33 можно добавить `verify:v=>…` (если верных ответов несколько), `ph` (подсказка в поле ответа) и рассуждения в `WHY` (первое — верное, все три — с одним ответом);
* `pool`: `train` (тренер, темы, разминка, «новый вариант»), `variant` (только фиксированные варианты), `diag` (диагностика);
* id должен быть новым и уникальным. Не переиспользуйте старые id: по ним считается, какие задачи ребёнок уже видел.

После правок запустите проверки (ниже).

## Проверки

```bash
npm install          # один раз: ставит playwright
npm test             # проверка банка + сквозной браузерный тест
```

* `tests/bank-check.js` — структура банка и **независимый пересчёт ответов перебором** для 317 задач (100 школьных — по формулам), включая все 56 задач вариантов (ребусы — перебором цифр, переливания — перебором состояний, турниры и кубы — подсчётом); у всех задач вариантов есть обоснования; ответы задач с рисунками пересчитываются по самому рисунку (периметр, квадраты, домино, перебор раскладок фигурок);
* `tests/e2e.js` — 136 браузерных проверок полных сценариев: две ветки и выбор при первом входе; контрольная с оценкой; будильник (цель, звонок через час, итоги, рост цели, итоги после перезагрузки, досрочное завершение); олимпиада без вариантов ответа → шаг обоснований → баллы; обоснование в тренировке; новые темы и варианты 6–7; тренер с разбором → задачи → выход → возврат → итог; просадка темы → разбор именно этой темы; тема, в которой закончились задачи, всё равно запускается; олимпиада → выход → перезагрузка → продолжить → завершить → статистика → следующий вариант; мобильная ширина; миграция старого прогресса; прогресс гостя после закрытия вкладки; инструкция по установке и файлы превью; все вкладки и служебные кнопки; отчёт «Мой прогресс» и учёт времени без простоя.
